Seltz

Bundles contain custom components that support specific third-party integrations with Langflow.

This page describes the components that are available in the Seltz bundle.

Seltz Search​

This component provides fast, up-to-date web knowledge with sources for real-time AI reasoning via the Seltz Web Knowledge API. Use it with a Langflow Agent component or MCP client to give your agents context-engineered web content.

The output is exclusively Tools.

Seltz Search parameters​

NameTypeDescription
Seltz API Key (api_key)SecretStringInput parameter. An API key for Seltz. Get one at console.seltz.ai.
Max Documents (max_documents)IntegerInput parameter. Maximum number of documents to return per search. Default: 10.
Search Context (context)StringAdvanced parameter. Additional context to improve search quality (e.g. "user is looking for Python documentation").
Search Profile (profile)StringAdvanced parameter. Search profile to use for different ranking algorithms or data source preferences.
